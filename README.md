# Linear_Regression          
    
НС для прогнозирования цены на акции.       
        
**Задача:**     
Обучить модель прогнозировать цену на акции компании Apple.     
       
**Использованные технологии:**       
Keras, Scikit-learn, TensorFlow           
        
**Как запустить проект**       
Создайте блокнот в Google Colab     
Скопируйте код из main.ipynb      
Запустите выполнение кода
